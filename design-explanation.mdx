## Setting Up Your Document

Returning to your answers about what size and style of map you'd like to make, the first thing we need to do is set up a page. As a reminder, you need to decide:

- where the map will be displayed,

- how it will be printed,

- and how large text must be readable from viewing distance.

Common poster sizes:

- 11" × 17"

- 18" × 24"

- 24" × 36"

- A2 / A1

### Create a New Illustrator Document

Open Illustrator and select: **File -> New .&#xA0;**&#x41; document setup window will appear.

Use the following settings:

| Setting        | Recommendation               |
| -------------- | ---------------------------- |
| Units          | Inches or millimeters        |
| Color Mode     | CMYK                         |
| Raster Effects | 300 ppi                      |
| Bleed          | 0.125 in (1/8") on all sides |

<Callout kind="tip" collapsed="false">
  Use CMYK for print, and bleeds prevent white edges appearing after trimming.
</Callout>

Then clic&#x6B;**&#x20;Create**. Your blank print document will open.

You should now see:

- a white artboard,

- a red bleed boundary around it.

### Save your document

**Save** onto the Adobe Cloud

- Log into Adobe Creative Cloud

- *File > Save*.

- In the *Save to Creative Cloud* window, type in a name and select *Save*.

## Import Your Maps

Now we have a clean slate, let's import your maps so we can edit them, add elements and redraw where necessary.

### Import your main map

Create a new layer and name it map\_main.

1. Go to: **File -> Place**

2. **&#xA0;**&#x4C;ocate your main map .svg file

3. Clic&#x6B;**&#x20;Place**

4. The&#x6E;**&#x20;click once** in the document.

To move the map into position select the circle on the right side of the layer in the layers panel, and then drag to where you'd like it.

## Edit Your Maps

Now we have our maps in Illustrator, let's start to edit and design them.

### Sort out your elements

Generally, the first thing I tell students to do when importing messy SVGs is to find the bits and pieces of your elements (like scale bars and north arrows) and to put them on a new layer. 

Go to **Window -> Layers.&#xA0;**&#x59;ou will probably see messy nested groups, clipping masks, unnamed layers.

Start by sorting out your layers.

### Design your map

Now, the time is for you to design your map. This is where you really start to work independently in articulating your site. Remember, the point of a map is to communicate spatial information, not visualize spatial data, so you need to think carefully and critically about what information is needed. 

#### Title + Description

Most maps will have a title and a description. Think carefully about font use and language.

#### Stroke, Fill and Texture

If you have resized your map, make sure all your lines are the same stroke, with the exception of lines made deliberately thicker for exaggeration. Consider changing the lines to dotted lines, altering the fill colors or patterns, or adding texture. 

#### Cartographic and Visual Elements

Are there other cartographic or visual elements that could help you tell your story or communicate information more holistically? Think about photographs or sketches (many maps have these to aid with navigation), whimsical elements like dragons, expressive cartouches or fancy north arrows. Don't be afraid to make new things and put the on the map - this is how the professionals do it, we don't do it in the GIS.
