### Define your scope

First, get into groups of 2-3 people.

<Steps>
  <Step title="Decide on a place" title-type="p">
    Choose a place that you would like to learn more about.

    Here is a list of the State Parks we will be working on:

    | Calaveras Big Trees SP        |
    | ----------------------------- |
    | Cuyamaca Rancho SP            |
    | Anderson Marsh SHP            |
    | Auburn SRA                    |
    | Ed Z'Berg Sugar Pine Point SP |
    | Sue-meg SP                    |
    | Ocotillo Wells SVRA           |
    | Anza-Borrego Desert SP        |
    | Humboldt Redwoods SP          |
    | Folsom Lake SRA               |
  </Step>

  <Step title="Find a map archive" title-type="p">
    Go to a map archive, such as <a href="https://www.davidrumsey.com/" target="_blank" rel="noopener noreferrer">[https://www.davidrumsey.com/](https://www.davidrumsey.com/)</a> 
  </Step>

  <Step title="Try some preliminary search terms" title-type="p">
    Maps are notoriously difficult archival objects to search. Try some search terms out, and figure out what scale you will need to search for.&#x20;

    If your park isn't working out, you might need to do some extra research on what city or county it is in and find maps of a larger scale.
  </Step>
</Steps>

### Find and Select Your Maps

Once you've figured out what scale you need to search for, find some maps which represent your park or place. Find 5-6 maps across different time scales (so, 1-2 maps per person).
