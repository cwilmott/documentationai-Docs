## Make a Plan

Now that we know what needs to go on the map (don't worry - this can change later), we need to figure out generally where it will all go and, more importantly, **what needs to be done in GIS, and what can be done in Illustrator**. 

Often, throughout a career as a cartographer, this is trial and error, finding new tools and new workflows - methods which can only be gained through experience.*&#x20;It is not unusual to get it wrong and to then have to start again - this is part of the process, an error, not a failure*. 

But, since you probably haven't done this before, I'll give you a quick overview of my preferences - workflow is one of the most hotly debated topics in professional cartography, and everyone disagrees (and in time, you may too). 

| **Feature**            | GIS                   | Illustrator | Best Option                            |
| ---------------------- | --------------------- | ----------- | -------------------------------------- |
| Page Size              | Only ArcGIS Pro, QGIS | Yes         | Illustrator                            |
| Orientation            | Only ArcGIS Pro, QGIS | Yes         | Illustrator (unless complex labelling) |
| Perspective            | Only ArcGIS Pro, QGIS | Yes         | GIS                                    |
| Insets                 | Only ArcGIS Pro, QGIS | Yes         | Illustrator                            |
| Context                | No                    | Yes         | Illustrator                            |
| Title and Description  | Yes                   | Yes         | Illustrator                            |
| Legend or Key          | Yes                   | Yes         | Combined workflow                      |
| Scale Bar              | Yes                   | Yes         | GIS                                    |
| Orientation arrow      | Yes                   | Yes         | Combined workflow                      |
| Labels and LeaderLines | Yes                   | Yes         | It depends                             |
| Neatline               | Yes                   | Yes         | Illustrator                            |
| Graticules             | Yes                   | Sort-of     | GIS                                    |

You can see from this list that you can do almost anything in each software - the question is which is the easiest and the most accurate for what you want to do.&#x20;

The main difference is that in GIS you have a coordinate geometry which ties everything together from scale bars to labels, and in Illustrator, you lose that coordinate geometry, but you gain the freedom to move features around, exaggerate or displace them.&#x20;

This means that in general, GIS is useful for mathematically heavy tasks and tasks where the consistency of geometry is important - and getting this foundation right, so it can be edited later in Illustrator. This includes tasks like:

- Choosing a projection

- Choosing a perspective

- Getting the correct scale for your scale bar

- Laying down graticules

- Getting your labels linked to the right points with leader lines to move them later

- Making sure your north arrow actually points north

- Getting the basics of your data addition, analysis and style  in the right location

These things are what we are going to be focusing on today. 

<Callout kind="danger" collapsed="false">
  Compared to ArcGIS Pro or QGIS, ArcGIS Online offers limited support for bespoke projections and perspectives. I am aware of this, and have taken it into account for the design of the Print Map Assessment.&#x20;
</Callout>

## Cartographic Layout in GIS

Depending on how you've filled out the sheet, and what elements you'd like to include - here is how to do the parts in GIS that need to be done.&#x20;

### Projection + Perspective

One of the biggest flaws of ArcGIS online is that you can't change the map projection and perspective easily. If you are doing this, it is far far better to do it on ArcGIS Pro or ArcGIS Online.

For these maps, you probably do not need to change the projection because the scale is so large it barely makes a difference. However, if you were making a map of *all* the parks, for instance, you would need to use a projection which adequately captures California. We will do this, but at the very end for your inset.

In terms of perspective, for this, it may be better to do it via Illustrator (download as an SVG, then shear it - <a href="https://helpx.adobe.com/illustrator/using/tool-techniques/shear-tool.html" target="_blank" rel="noopener noreferrer">https\://helpx.adobe.com/illustrator/using/tool-techniques/shear-tool.html</a>)

### Graticules

Again, this is easier in GIS software, but can still be done via ArcGIS Online. Basically, you use geoprocessing to create a grid layer in ArcPro and then upload it to ArcOnline.&#x20;

Thankfully, NOAA has already made a webserver for us to use:

<Card title="Graticule ArcServer" href="https://www.arcgis.com/home/item.html?id=503cc3f56e814c4384b9dcd9ef6ee697" icon="grid" cta="Find server here" horizontal="false" target="_self">
  You can find NOAA's graticle Arc REST server here.
</Card>

To use this:

1. Click on the link

2. Click on the degree layer you'd like.&#x20;

3. Once you're on the Arc REST Services directory, copy and paste the web address.

4. Go back to your map on ArcGIS Online

5. On your basemap layer, click Add Layer -> Add Layer from URL

6. Copy and paste the URL

7. If it's correct, the Type of Layer field will auto set to ArcGIS Web Server

8. Then hit Next.

## Style Your Data

The limits to designing, composing and styling geographic information on GIS systems is one of the *key&#x20;*&#x72;easons cartographers use vector illustration software, like Illustrator. At the same time, *we need to get that data from somewhere*. This week is all about the in-between zone where you are styling information *as best you can* in GIS while preparing it for illustrator.

<Callout kind="tip" collapsed="false">
  Your map will be exported into an .svg format ready for Illustrator at the end of this tutorial. Don't worry if you can't get ArcGIS to do what you want - fixing things in Illustrator is the domain of the cartographer!
</Callout>

### The Properties sidebar

When you click on your feature layer, a side bar appears on the right. You can style your data here.&#x20;

Different kinds of data will have different options for styling - a point might have a symbol, while a polygon might have a fill color. You can also color features according to their numeric or categorical attributes (i.e. all features with the category 'closed' are red; all features which have a value between 100 and 250 are green.

<Tabs>
  <Tab title="Locations">
    Locations are in **point**, **line** and **polygon** format, and tend to be styled as **shapes** or **symbols**.&#x20;

    **Shapes** have: a fill color, an outline color, a fill transparency, an outline transparency, an outline width, a fill pattern, an outline pattern.

    **Symbols** are either small raster or vector objects which may or may not have: transparency and color options.

    Read more <a href="https://doc.arcgis.com/en/arcgis-online/create-maps/style-location-mv.htm" target="_blank" rel="noopener noreferrer">here</a>
  </Tab>

  <Tab title="Number">
    **Number** refers to quantitative values which are attributes of your feature data. They might be individual numbers, or have ranges or other calculated fields (like min or max).

    **Numbers** can be used to style: **color**, **symbol, size**, **transparency**

    Read more <a href="https://doc.arcgis.com/en/arcgis-online/create-maps/style-numbers-mv.htm#ESRI_SECTION1_5746532688614A4C805AACCBFE18BD0C" target="_blank" rel="noopener noreferrer">here</a>&#x20;

    My advice is to play around and see what you can do, but you can also learn more about styling your map data here:
  </Tab>

  <Tab title="Categories">
    Categories are qualitative descriptions of data (like park or road).

    Categories can be styled according to: **color, symbol, transparency, size&#x20;**(but this is less meaningful).

    Read more <a href="https://doc.arcgis.com/en/arcgis-online/create-maps/style-categories-mv.htm" target="_blank" rel="noopener noreferrer">here</a>
  </Tab>
</Tabs>

My advice is to just play around with the styling options to see what they can do, and trust your instincts about what looks good.

ArcGIS Online has a legend tool if you need to display complex information.

## Download your map

The next stage is to download your map.

<Steps>
  <Step title="Go to Print" title-type="p">
    On the left sidebar, select **Print**
  </Step>

  <Step title="Choose size" title-type="p">
    Choose the **file size** for your map that you think you will need (you can adjust this in Illustrator, but it's a little tricky).
  </Step>

  <Step title="Choose format" title-type="p">
    In the **Format** dropdown, choose **.svg**&#x20;
  </Step>

  <Step title="Add Elements" title-type="p">
    In **Advanced Options** you can choose to add elements such as a scale bar or a north arrow.&#x20;
  </Step>

  <Step title="Export" title-type="p">
    Now click **Export**.&#x20;
  </Step>

  <Step title="Save" title-type="p">
    Save your .svg folder, alongside your completed form on your Google Drive for submission.
  </Step>
</Steps>

## Make an Inset Map

An inset map is useful for giving spatial context across multiple scales. For our inset map, we will use a map of California to show where your site is.

### Projection

ArcGIS Online uses web mercator, which distorts the shape and size of the state. The California State Government's standard projection is California Albers (EPSG:3310 / NAD83). There are two main ways in which cartographers change projection:

- The first is th&#x65;**&#xA0;cheats way** which only works for **print base maps without data** - you take a screenshot on a mapping tool like the ones in the lecture, and trace it using Illustrator or Photoshop.

- The second is to use either **ArcGIS Pro** on your Windows computer, or **QGIS** on your Mac. See Sections 6 and 7 of the QGIS User Manual here: [<a href="https://docs.qgis.org/3.44/en/docs/user_manual/working_with_projections/working_with_projections.html" target="_blank" rel="noopener noreferrer">https://docs.qgis.org/3.44/en/docs/user\_manual/working\_with\_projections/working\_with\_projections.html</a>](https://docs.qgis.org/3.44/en/docs/user_manual/working_with_projections/working_with_projections.html)

But neither of these will work for us. The first one risks losing the scale and geometric relationality of the map, and we don't have access to the tools for the second one.&#x20;

Luckily, enough people complained to ESRI and they came up with this workaround that we will follow:
