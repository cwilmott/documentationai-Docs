  Before class ends, you need to make sure you have completed these steps to
  finalize your part in the project!

### Your code

Make sure any code is available via Github with documentation on the structure.

### Your assets

**Content:**\
Make sure all copy, images and other materials are available in your Google Drive Folder

**Assets:**\
Make sure all fonts, glyphs, sprites, color swatches etc... are available in your Google Drive Folder

### Notes and emails

Make sure that any notes, or emails that have been exchanged are saved as Google Docs in your Google Drive Folder

### Your notes

Make sure your **Notes Google Doc** is saved in the Google Drive and shared with the instructor.
