## Hardware

This course has designed to be technically lightweight, and browser-based as far as it can go. You will need the following to run the software:

- A computer with a web browser and a basic level of RAM.

- A phone or camera for taking pictures of your work and uploading it.

An iPad or similar may be helpful for your work but is not a requirement. Similarly, there is a considerable amount of this course which can be undertaken on an iPad - you are welcome to try, but I won't be able to support it technically.
