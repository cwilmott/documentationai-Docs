### **Format&#x20;**

Maps must be submitted as a link to your <a href="http://github.io" target="_blank" rel="noopener noreferrer"><u>github.io</u></a> web map website, and link to your code repository - unless you have permission to do otherwise.

Your map must have:

- A custom basemap (Mapbox)

- Markers, icons, or other data features

* The name of the cartographer (you), the year the map was produced and an acknowledgement of source data - either on the map itself or nestled as a comment in the html.

- A pop-up (Attribute Information)

* A web mapping element that uses HTML, CSS or (preferably) JS that I did not teach you how to do in the labs.

### Cartographic Exegesis

Each map must be accompanied by a short c. 1000 word essay explaining your design choices for your base map, along with other choices you made, debugging you undertook, and what you tried to do (even if it did not work). You will be graded on the rubric below.

Finally, remember, grades are additive, not deductive. You do not have to achieve highly in each category to get a good grade, if you are exceptional in one or two.
